# Finance Calculators

## A python code to calculate either a return on interest or a home loan bond repayment

The code allows the user to choose one of two calculations they would like to perform, namely "investment" or "bond".

**If the option "investment" is selected:**
  The user will first be requested to input the amount of money being deposited for investment calculation.
  Next, the user will be asked to input the interest rate and the numbers of years of the investment.
  Then, the user will be asked to enter what type of interest - simple or coumpound.
  Finally, the code will calculate and return the amount earned based on the user inputs. 

**If the option "bond" is selected:**
  The user will first be requested to input the present value of the house for bond calculation.
  Next, the user will be asked to input the interest rate and the numbers of months of bond repayments.
  Finally, the code will calculate and return the amount of the bond repayment each month base on the user inputs.
